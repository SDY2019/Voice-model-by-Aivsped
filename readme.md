

# Голосовой помощник для задач и встреч

Прототип персонального ассистента на Python. Позволяет создавать задачи,
напоминания и встречи, получать список событий за период и искать
ранее созданные записи по текстовому запросу.

## Возможности

- Создание задач и напоминаний.
- Создание встреч с уточнением даты или времени, если их не хватает.
- Просмотр событий на сегодня, завтра и текущую неделю.
- Поиск по старым задачам и встречам с использованием нечёткого
  текстового сравнения.
- Сохранение данных между перезапусками в SQLite.
- Текстовый и голосовой ввод.
- Озвучивание ответов на русском языке.

## Технологии

- Python 3.11+
- FastAPI — HTTP API и сервер приложения.
- SQLite — постоянное хранение данных.
- Regular expressions и словари синонимов — обработка запросов.
- difflib — поиск похожих текстов без внешних AI-сервисов.
- HTML, CSS и JavaScript — интерфейс.
- Web Speech API — распознавание и синтез речи в браузере.

## Запуск

### 1. Установить Python

Рекомендуется Python 3.11 или новее.

### 2. Создать виртуальное окружение

Linux/macOS:

```bash
python -m venv .venv
source .venv/bin/activate
```

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Запустить сервер

```bash
uvicorn app:app --reload
```

### 5. Открыть приложение

Перейти в браузере по адресу:

http://127.0.0.1:8000

Документация API доступна по адресу:

http://127.0.0.1:8000/docs

База данных `assistant.db` создаётся автоматически рядом с `app.py`.

Для голосового ввода рекомендуется Chrome. Поддержка распознавания
речи зависит от браузера и его настроек. В некоторых браузерах
распознавание выполняется внешним сервисом браузера, поэтому
голосовой ввод не гарантирует полностью автономную работу.

## Примеры запросов

- «Напомни мне завтра в 10 утра позвонить Ивану».
- «В пятницу нужно отправить отчёт».
- «Поставь задачу купить билеты до конца недели».
- «Добавь встречу с командой завтра в 15:00».
- «Добавь встречу с дизайнером завтра» — ассистент запросит время.
- «Что у меня сегодня?»
- «Какие встречи у меня сегодня?»
- «Какие задачи у меня на завтра?»
- «Что запланировано на эту неделю?»
- «Найди задачу про презентацию».
- «Когда у меня была встреча с Иваном?»

## Архитектура

1. Браузер принимает текст или распознаёт голос.
2. FastAPI передаёт запрос модулю обработки естественного языка.
3. Правила определяют намерение, дату, время и название записи.
4. Бизнес-логика создаёт запись, формирует список или выполняет поиск.
5. SQLite хранит события между запросами и перезапусками.
6. Ответ отображается в чате и при поддержке браузера озвучивается.

## Принятые решения

Вместо языковой модели использованы правила, регулярные выражения,
обработка относительных дат и нечёткое текстовое сравнение. Это
уменьшает количество зависимостей и позволяет работать без API-ключей.

Для прототипа выбрана SQLite: она не требует отдельного сервера базы
данных и подходит для локального приложения.

## Ограничения

- Обработка естественного языка основана на правилах, поэтому не все
  свободные формулировки будут распознаны.
- Предназначен исключительно для локального использования
- Часовой пояс, повторяющиеся события, конфликты встреч, редактирование
  и удаление записей требуют дальнейшей реализации.
- В Firefox не работает голосовая поддержка, только в браузере на движке Chromium

## Что можно улучшить

- Добавить тесты для распознавания намерений и дат.
- Вынести NLP, бизнес-логику и работу с БД в отдельные модули.
- Расширить словарь синонимов и обработку русских падежей.
- Добавить редактирование, удаление и завершение задач.
- Добавить проверки конфликтов встреч и повторяющиеся события.
- Реализовать пользователей, авторизацию и контекст диалога в БД.
- Добавить полноценный семантический поиск без передачи данных сторонним
  сервисам.
- Добавить CI, логирование и развёртывание на публичном сервере.
- Добавить возможность голосовой поддержки в Firefox и других браузерах, не работающих на движке Chromium


## 4. Проверка основных сценариев

После запуска сервера можно проверить API через `/docs` или выполнить запросы из терминала.

Пример создания напоминания:

bash

```
curl -X POST http://127.0.0.1:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Напомни завтра в 10 позвонить Ивану"}'
```

Пример просмотра планов:

bash

```
curl -X POST http://127.0.0.1:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Что у меня завтра?"}'
```

Пример поиска:

bash

```
curl -X POST http://127.0.0.1:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Найди задачу про презентацию"}'
```
